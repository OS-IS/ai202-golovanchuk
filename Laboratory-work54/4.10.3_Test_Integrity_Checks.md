# 4.10.3 Тест перевірки цілісності

Тест визначає, чи використовує система механізми контролю цілісності
(наприклад, криптографічні хеші, підписи, контрольні суми), які гарантують,
що дані не були змінені під час передавання або зберігання.  

Відсутність перевірок цілісності може дозволити зміну важливих даних у повідомленнях,
конфігураційних файлах або базі даних без виявлення.
